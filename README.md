# Projeto Vue.js com Vuetify

Este projeto demonstra o uso de componentes do Vuetify 3 em uma aplicação Vue.js.

## 🚀 Tecnologias Utilizadas

- Vue.js 3
- Vuetify 3
- SCSS
- Axios

## 📋 Pré-requisitos

- Node.js (versão 14 ou superior)
- npm ou yarn

## 🔧 Instalação

1. Clone o repositório
```bash
git clone [url-do-repositorio]
```

2. Instale as dependências
```bash
npm install
```

3. Execute o projeto
```bash
npm run serve
```

## 🎨 Componentes Demonstrados

- **CardExample**: Demonstração de cards com Vuetify
- **ConsoleMessager**: Exemplo de botões e console.log
- **ModalExample**: Implementação de modais
- **SnackbarExample**: Notificações usando snackbar
- **TableExample**: Tabela com dados da API
- **ToolbarExample**: Barra de navegação
- **GridLayout**: Layout responsivo com grid

## 🎯 Funcionalidades

- Tema personalizado com cores verde e amarelo
- Botões com estilo customizado (arredondados e sombras)
- Componentes interativos
- Layout responsivo
- Integração com API externa

## 📦 Estrutura do Projeto

```
src/
├── assets/         # Arquivos estáticos
├── components/     # Componentes Vue
├── plugins/        # Plugins (Vuetify)
├── styles/         # Arquivos SCSS
└── App.vue         # Componente principal
```

## 🛠️ Scripts Disponíveis

- `npm run serve`: Inicia o servidor de desenvolvimento
- `npm run build`: Compila o projeto para produção
- `npm run lint`: Executa o linter
